# ADR 0001: Stack

Status: accepted (2026-10-18)

## Decision

- Web: Next.js (App Router), TypeScript strict, Tailwind, shadcn/ui.
- Analytics: Python FastAPI service (pandas, numpy, statsmodels) under `services/analytics`.
- DB: PostgreSQL 16, Drizzle for migrations/queries from TypeScript.
- Monorepo: pnpm workspaces for TypeScript, uv for Python.
- LLM: OpenAI API (decided 2026-10-19; default model `gpt-6-sol`, same as the sibling logistics-ai project), structured outputs through the Responses API, every call logged to `llm_runs`. The classifier sits behind a `Classifier` interface, so the provider is swappable.

## Context

Event studies, covariance shrinkage and regressions are materially easier and more trustworthy in Python. The product UI and API are best kept in one TypeScript codebase.

## Consequences

Two deployables. The contract between them is an OpenAPI schema generated by FastAPI; the TypeScript client is generated from it. Job queue is Postgres-backed (pg-boss) to avoid Redis in V1.
