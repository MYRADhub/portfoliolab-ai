# ADR 0004: Hidden concentration metric

Status: open, must be accepted before Phase 4

## Candidates

1. HHI over normalized absolute portfolio factor loadings.
2. Effective number of independent bets from the factor covariance eigenvalues.
3. Largest single-factor share of total absolute exposure.

## Proposal

Compute all three. Pre-register one as the primary outcome for the experiment before any participant data is collected.
